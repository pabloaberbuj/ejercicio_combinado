# Installation


## Stable release

To install ejercicio_combinado, run this command in your terminal:

```batch

    $ pip install ejercicio_combinado
```

This is the preferred method to install ejercicio_combinado, as it will always
install the most recent stable release.

If you don't have [pip](https://pip.pypa.io) installed, this 
[Python installation guide](http://docs.python-guide.org/en/latest/starting/installation/) 
can guide you through the process.


## From sources

The sources for ejercicio_combinado can be downloaded from the 
[Github repo](https://github.com/pabloaberbuj/ejercicio_combinado).

You can either clone the public repository:

```batch

    $ git clone git://github.com/pabloaberbuj/ejercicio_combinado
```

Or download the [tarball](https://github.com/pabloaberbuj/ejercicio_combinado/tarball/master):

```batch

    $ curl  -OL https://github.com/pabloaberbuj/ejercicio_combinado/tarball/master
```

Once you have a copy of the source, you can install it with:

```batch

    $ python setup.py install
```
